# Zomato Sales Analysis

A data analytics project for exploring Zomato sales and order data. Use the project files to understand the analysis and extend the reporting workflow.

## Project overview

This project analyzes Zomato sales data in Excel and presents key findings in an interactive dashboard. It is designed to help explore sales performance and related trends.

## Excel tools used

- **Pivot tables** to summarize the sales data.
- **KPIs** to give a quick view of key performance measures.
- **Filters and slicers** to explore and refine the dashboard data interactively.

## Getting started

1. Review the project files and open the analysis in the application or environment used by that file type.
2. If the project includes code, install the dependencies listed by that project before running it. If it includes a dashboard file, open it with the compatible reporting application.

## Analysis questions

This project can be used to investigate questions such as:

- How do sales and order volumes change over time?
- Which restaurants, cuisines, or locations contribute most to sales?
- What patterns appear in order value and customer activity?
